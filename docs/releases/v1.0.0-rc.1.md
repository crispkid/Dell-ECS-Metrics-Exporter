# Dell ECS Metrics Exporter v1.0.0-rc.1

This is the first public release candidate for Dell ECS Metrics Exporter. It is intended for
evaluation and integration testing, not production approval.

## Included

- Multi-cluster Dell ECS collection with Prometheus metrics, cache-backed health and an
  authenticated read-only Inventory API.
- Compatibility Profiles for ECS 3.6.x, 3.7.x, 3.8.0.x and 3.8.1.x, with fail-closed unknown
  version handling and explicit version-specific Flux policies.
- Docker/OCI, Kubernetes/Helm and hardened Linux Bare Metal/systemd deployment assets.
- A redacted, read-only `ecs-flux-probe` for exact-build compatibility evidence.
- Signed multi-architecture OCI images, release archives, Helm OCI chart, checksums, SBOMs and
  OCI provenance produced by the release workflow; GitHub-native attestations are added when the
  repository visibility/plan supports them.

## Validation represented by this RC

- Shared Management and Flux latest-snapshot functions have qualifying live evidence on at
  least one target ECS version and use the documented `shared-live-any-target-version` policy.
- ECS CE 3.8.0.3 and 3.8.1.4 provide partial Management API evidence.
- Physical ECS 3.8.1.1 provides partial Node CPU, memory, network and Performance Flux evidence.
- Deterministic tests, race detection, coverage, security checks and synthetic
  10-cluster/100-node/10,000-bucket checks are release gates.

## Known limitations before stable v1.0.0

- Exact physical ECS 3.8.1.4 certification has not been completed.
- Deployed target-scale CPU, RSS, Inventory latency and response-size evidence remains pending.
- A tagged deployment has not yet completed the protected end-to-end workflow.
- Node service/process, Disk, Flux interval-derived rates, replication status/lag and recovery
  progress have not received qualifying live evidence on any target version.
- Bucket-scope Performance is unavailable by design. ECS CE Flux node-resources returned HTTP
  503 in the tested CE environments and is not treated as an appliance limitation.
- No named Project Maintainer and independent Security Reviewer approval is recorded for stable
  production use.
- The current repository is private. If it is not covered by GitHub Enterprise Cloud, GitHub-native
  artifact attestations are unavailable; the RC instead publishes the signed
  `github-attestation-boundary.txt`, checksums, SBOMs and OCI provenance/signatures. Stable
  `v1.0.0` continues to require GitHub-native attestations.

Review `docs/RC_RELEASE_CHECKLIST.md`, `docs/RELEASE_CHECKLIST.md` and the README compatibility
matrix before deployment. Pin production-like evaluations to immutable digests or verified
checksums; do not use mutable tags.
