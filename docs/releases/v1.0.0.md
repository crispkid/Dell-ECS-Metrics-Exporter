# Dell ECS Metrics Exporter v1.0.0

This is the first stable release of Dell ECS Metrics Exporter. It provides a
read-only, multi-cluster Prometheus exporter and Inventory API for supported
Dell ECS 3.6.x, 3.7.x, 3.8.0.x and 3.8.1.x systems.

## Included

- Capacity, health, quota, billing, node resource, performance, replication and
  recovery collection through explicit compatibility Profiles.
- Prometheus metrics, cache-backed health and an authenticated read-only
  Inventory API.
- Automatic Profile selection with fail-closed handling for unknown or
  incompatible mixed versions.
- Release archives for Linux and macOS on amd64 and arm64.
- Signed multi-architecture OCI images, an OCI Helm Chart, checksums and SBOMs.
- Docker, Kubernetes/Helm and hardened Linux Bare Metal/systemd deployment
  options.
- Go 1.26.6 build and runtime binaries, including the standard-library security
  fixes required by the release vulnerability gate.
- `golang.org/x/mod` v0.40.0 for the pinned security tooling dependency, which
  resolves GO-2026-6179 and GO-2026-6180 reported during the stable release
  dependency scan.

## Compatibility evidence

- Shared Management and Flux latest-snapshot functions have qualifying live
  evidence on at least one supported ECS version.
- ECS CE 3.6.2.0, 3.7.0.0, 3.8.0.3 and 3.8.1.4 provide Management API
  compatibility evidence for their applicable collectors.
- Physical ECS 3.8.1.1 provides Node CPU, memory, network and Performance Flux
  evidence.
- The user has additionally confirmed successful physical ECS
  3.8.0.x and 3.8.1.x Exporter compatibility tests. Exact four-part builds and
  redacted reports were not supplied with that confirmation, so it is not
  represented as machine-verifiable `tested_builds` or full Profile
  certification.

The stable release uses the user-attested physical compatibility record together
with automated deterministic, race, container, deployment, synthetic
target-scale, vulnerability, license, image scan, signature and artifact gates.
Protected exact-build, deployed end-to-end and deployed target-scale jobs remain
available when `RUN_PROTECTED_LIVE_GATES=true` is configured for environments
that provide the required self-hosted runners and secrets.

Because the repository is public, this release produces GitHub-native
provenance and SBOM attestations. Signed checksums, source and platform SBOMs,
BuildKit OCI provenance/SBOM attestations, and keylessly signed OCI image and
Helm Chart manifests are also included.

## Known limitations

- ECS 3.7.x and 3.8.0.x keep interval-derived Flux rates disabled because of
  the documented ECS time-range behavior. ECS 3.8.1.x enables them only after
  the environment-specific range gate passes.
- ECS Community Edition may return HTTP 503 from Flux External Query while
  Management collectors remain usable; this is not generalized to physical
  appliances.
- Bucket-scope Performance is unavailable by design. Conditional Node Disk,
  service/process and recovery capabilities require explicit configuration.
- Repository, Release, Container Image and Helm Chart access follows the
  repository's current visibility and GitHub package permissions.

Pin deployments to the immutable Image Digest in `image-digest.txt` or verify
downloaded archives with `SHA256SUMS`.
