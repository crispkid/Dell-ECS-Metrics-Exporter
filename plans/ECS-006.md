# ECS-006 Execution Plan

## Purpose and Observable Outcome

完成規格稽核中十個尚未實作或實作不完整的 runtime 項目。完成後，Exporter 會把
已驗證形狀的 VDC/Namespace Flux performance response 轉成原子快取與 Prometheus
Gauge、以明確設定啟用 conditional capability、補齊可由既有 response 取得的 Node
disk/service/process 與 Inventory 欄位、停止輸出超過 `maxStale` 的 domain series，
並提供 per-cluster rate limiting、啟動 jitter、bounded network/disk policy、batch
Bucket billing、response-size telemetry 與精確 cache-refresh telemetry。

此 change 只完成可由 synthetic fixture/mock transport 證明的程式行為，不把任何
Profile 升級為 sandbox certified，也不宣稱 ECS 3.8.1.4 或正式 Flux 已通過。

## Context and Constraints

- Governing contracts: `SPECIFICATION.md` REQ-002–REQ-012、
  `DELL_ECS_API_MAPPING.md`、`docs/ecs-api/common-contract.md`、`TEST_PLAN.md`。
- `/metrics` 只能讀 cache；Performance、Bucket batch 或 Node resource 任一完整
  refresh 失敗時不得覆蓋最後成功 snapshot。
- Performance 來源為 window/snapshot 時一律使用 Gauge；不得映射成 Bucket scope，
  也不得使用 `_total` Counter。
- Conditional capability 只有在 Profile 為 `conditional` 且 cluster config 明列時
  才能啟用；`unavailable` 與 mixed-version 被停用的能力不可覆寫。
- Node disk 只聚合明列 filesystem；network interface 需受 allowlist、最大數量與
  bond/member policy 約束。
- 不新增未經 mapping 證實的 ECS URI。Service/process 只解析既有 Node health
  response 的 optional fields；沒有欄位時保持空集合。
- Profile certification schema 可以表達未來真實 evidence，但目前四個 Profile 的
  `tested_builds=[]`、`sandbox_certified=false` 保持不變。
- 不記錄 credential、token、完整 URL/query、private endpoint 或 raw response。

## Surprises and Discoveries

- 現有 Performance Collector 只驗證 Flux envelope 並丟棄資料，卻仍把 collector 與
  cache refresh 計為成功。
- `conditional` capability 目前永遠停用，但 Recovery Collector 又未檢查
  `recovery_progress` capability。
- Bucket billing mapping 已要求優先使用 Namespace batch endpoint，runtime 仍逐
  Bucket 查詢。
- Billing `sample_time` 被誤用為 Bucket `lastModifiedAt`；應獨立保存 usage sample
  timestamp。
- Profile schema 1.0 把 `sandbox_certified` 固定為 false，未來即使完成認證也無法
  表達。
- 全域 cache generation 會把其他 collector 或 bootstrap 的 mutation 誤算成當前
  refresh；已改為 per-cluster/per-domain generation。
- `skipped` 若沿用一般 successful finish，會刷新 last-success 並讓舊 domain
  series 永遠不過期；已新增 skipped finish，保留既有 last-success 讓 `maxStale`
  正常生效。

## Decision Log

- 2026-07-25 — 新增 VDC/Namespace performance Gauge contract；只接受明確
  measurement/field/unit/scope，保留原始 VDC/Namespace scope，不輸出 Bucket
  performance。Accountable role: Project Maintainer；沒有具名 reviewer 核准。
- 2026-07-25 — Conditional capability 使用 cluster-level
  `capabilities.enabledConditional` 顯式啟用；不能覆寫 `unavailable`，mixed-version
  interval rate 仍強制停用。
- 2026-07-25 — Node service/process 不新增 URI，只解析現有 Node health response
  optional arrays；未知狀態拒絕整次 refresh。
- 2026-07-25 — `maxStale` 只停止 domain series；build/Profile/cache age/last-success
  等 self metrics 持續輸出，讓 operator 能判斷原因。
- 2026-07-25 — Bucket billing 先使用 batch POST；endpoint 明確不支援時或 batch
  缺項時才以 bounded 單筆 GET 補齊，完整成功後才替換 cache。
- 2026-07-25 — Network Counter 保留 ECS raw cumulative value，reset 交由
  Prometheus Counter semantics 處理；Exporter 不製造跨重啟 offset。

## Implementation Plan

1. 擴充 config/Profile contract：rate limit、conditional capability、filesystem/
   interface policy 與可表達 future sandbox evidence 的 schema。
2. 擴充 model/cache：Performance、Node service/process、usage sample timestamp、
   deep copy/sort/generation。
3. 實作 Performance、Node disk/service、batch billing、TB/ms parser 與嚴格
   cardinality/scope/unit validation。
4. 更新 Runner：conditional guard、Performance replacement、Recovery guard、
   Node policy、batch billing 與精確 refresh telemetry。
5. 更新 ECS client/scheduler：per-client token bucket、response-size observer 與
   initial jitter。
6. 更新 Prometheus：Performance/service descriptors、response-size histogram、
   per-domain `maxStale` cutoff。
7. 新增 fixture/component tests 並同步 public documentation/governance。

## Recovery and Idempotence

- 所有新設定有安全預設；舊 config 不需 migration 即可啟動。
- Conditional/disk 能力預設關閉，只有明確設定才增加 ECS query surface。
- Batch billing 只讀，回退單筆 GET 亦只讀；任何不完整結果不替換 cache。
- Rate limiter、scheduler 與 parser 無持久狀態；重啟後安全重建。
- 移除新設定即可回復先前 capability 行為；cache 失敗保留最後完整資料。
