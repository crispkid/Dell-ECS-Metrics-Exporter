# ECS-010 Execution Plan

## Purpose and Observable Outcome

Provide defensible compatibility validation when physical ECS 3.6, 3.7 and 3.8.0 appliances
are unavailable locally. The outcome is an official-document reconciliation, deterministic
four-profile replay, and a portable read-only redacted Probe that can collect candidate
exact-build evidence without raw ECS data.

## Context and Constraints

- Only an ECS 3.8.1.1 physical appliance has been observed; other available environments are
  ECS Community Edition and cannot prove production fabric/Flux compatibility.
- Probe queries must match Exporter production collectors and parsers.
- No endpoint, credential, token, resource identity, raw response or sample value may enter
  the report or repository.
- Fixture replay, CE behavior and Probe exit status do not populate `tested_builds`, set
  `sandbox_certified=true`, or satisfy production Gate 4.
- 3.6/3.7/3.8.0 exact appliance execution depends on an external operator.

## Decision Log

- Output exact ECS build because it is necessary evidence, but omit every resource identity.
- Output only series counts, never sample values or raw responses.
- Default Performance checks on; default conditional Disk off and require a filesystem
  allowlist when enabled.
- Treat setup/bootstrap/Profile failure as `failed`; later check/logout failure as `partial`.
- Keep interval policy from each resolved Profile; do not infer capability from fixture success.
- Include the Probe in normal and release builds so evidence can be tied to the Exporter commit.

## Verification Plan

- Targeted `internal/fluxprobe` and CLI tests.
- `go test -race -count=1 -timeout=3m ./...`.
- Harness doctor and required deterministic stages, followed by full `verify`.
- Build and deterministic release archive regression.
- Final credential/private-endpoint scan and diff review.

## Remaining Evidence Boundary

Under ECS-011, qualifying live evidence validates the same feature across all target Profiles.
Exact reports remain useful for known version differences and release-candidate deployment gates.
